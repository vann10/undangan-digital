# Arsip historis

| Folder | Isi |
| --- | --- |
| `reviews/` | Laporan revisi visual, audit, checklist lama, dan checkpoint |
| `specifications/` | Brief serta spesifikasi awal, termasuk rencana backend yang diganti |
| `agent-prompts/` | Prompt alur kerja agen terdahulu |

Arsip dipertahankan sebagai rekam keputusan. Instruksi fase, tanggal, status PASS/PENDING, dan path di dalamnya merupakan catatan pada saat ditulis. Gunakan [dokumentasi aktif](../README.md) dan kode aplikasi untuk pekerjaan baru.

Screenshot dan hasil pengujian lama dikeluarkan dari source control. Pada workspace yang dirapikan tanggal 29 Oktober 2026, salinan lokal berada di `.local/repository-cleanup/artifacts/`; manifest pemindahan berada di `.local/repository-cleanup/manifest.json`. Clone baru dapat membuat bukti baru dengan skrip pengujian yang relevan.
